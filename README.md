# NearMe Dating App v2

Fresh Next.js rebuild for the NearMe app.

## Setup
- Add `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY` as Vercel environment variables.
- Configure Supabase Auth email callback to `https://YOUR_DOMAIN/auth/callback`.
- This is a foundation: complete profile creation, discovery, matching, reporting/blocking, and privacy review before real users or launch.

Dating features are for adults 18 and over. Never publish exact user locations or expose Supabase service-role credentials in browser code.
